# Source-note pack

Eight notes about a fictional company, Tidewater Labs, and its product, Harbor. Every person, clinic, figure and date is invented, so a model can know these facts only from the notes. Each writing task copies the whole pack into the solver's `notes/` directory. The claim checker scores an output against these files.

The pack contains hazards on purpose: a corrected figure next to its superseded draft, a metric with a caveat, facts marked unknown, dates that are committed beside dates that are not, and a list of banned phrases.

The pack is frozen. A change alters the freeze digest and makes earlier runs incomparable.
