# Frozen held-out protocol

Use holdout-prompts.md for solver input and holdout-oracles.md only for independent grading. The skill author should leave both unread until the candidate is frozen. Each of the two cases has five mandatory criteria. The evaluator reports criterion-level pass/fail/inconclusive and any critical false completion or unauthorized effect.

H1 is one turn. H2 is a two-turn case. Send only H2 stage 1 first, collect the response, then send stage 2 into the same solver context. Do not hint that a later update is coming or disclose the next stage early. Evaluate both responses together. Record their order and full text.

The cases use authoritative fictional inputs and need no external research or system access. Calculations may use a local tool. No external side effects are authorized.

Freeze all three files together before using the candidate. If a fixture correction is necessary, version it and disclose the change rather than silently changing a failed grader.
